# Archived arcade games

JezzBall and Flappy Birds as they existed immediately before the October 11, 2026 rebuild, restored from commit `c4fdb87`. Their game code and styles are preserved, including snapshots of shared navigation and styles.

Only the navigation root and a link back to the current game were added. Open `jezzball.html` or `flappybirds.html` using the repository’s static server.
